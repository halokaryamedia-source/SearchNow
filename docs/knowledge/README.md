# Knowledge / Repository Memory

This directory holds SearchNow continuity and engineering knowledge that should survive chat/session boundaries without becoming permanent product-policy clutter.

```text
next-action.md          active continuation only
ownership.md            who owns each boundary
source-authority.md     evidence/decision precedence
work-routing.md         compact mode routing
work-modes/             development/maintenance lifecycle
decisions/              durable rationale crossing task boundaries
operations/             non-active backlog/operational notes
reviews/                current and historical validation evidence
```

Rules:

- active work belongs in `next-action.md`;
- future/non-active work belongs in `operations/backlog.md`;
- durable cross-task rationale belongs in `decisions/`;
- validation evidence belongs in `reviews/`;
- legacy BlueCoin evidence belongs in `docs/legacy/`, not here.
